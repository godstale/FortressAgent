# Fortress 사용자 가이드 (User Guide)

Fortress는 **Ollama 로컬 LLM**을 기반으로 동작하는 개인용 AI 에이전트 데스크탑 워크스테이션입니다. 모든 대화, 코드 분석, 문서 작성, 파일 편집이 사용자의 로컬 환경에서 완전히 비공개(Private)로 수행됩니다.

---

## 1. 시작하기

### 1.1 사전 요구사항
1. **Ollama 설치**: [ollama.com](https://ollama.com)에서 Ollama를 설치하고 실행합니다.
2. **로컬 모델 준비**: 터미널에서 권장 모델을 다운로드합니다.
   ```bash
   ollama run qwen2.5-coder:7b
   # 또는
   ollama run llama3.1:8b
   ```
3. **Fortress 실행**: 앱을 실행하면 기본적으로 `http://127.0.0.1:11434`에 연결된 Ollama 인스턴스를 자동으로 감지합니다.

---

## 2. 핵심 워크스페이스 개념

### 2.1 워크스페이스 폴더 열기
- 좌측 상단 탐색기 패널에서 "폴더 열기" 버튼을 클릭하여 프로젝트 작업 디렉터리를 선택합니다.
- **신뢰 확인(Trust Workspace)**: 폴더를 처음 열면 해당 디렉터리의 `AGENTS.md` 지침 및 `.agents/skills/` 스킬을 신뢰하고 로드할지 확인하는 대화상자가 표시됩니다.

### 2.2 프로젝트 컨텍스트 (`AGENTS.md`)
- 작업 디렉터리 또는 상위 디렉터리에 `AGENTS.md`(또는 `CLAUDE.md`) 파일을 생성하면, 에이전트가 대화 시 프로젝트 지침, 코딩 컨벤션, 아키텍처 규칙을 자동으로 인지합니다.
- 계층적 수집: 루트 조상 디렉터리부터 작업 디렉터리 순서로 지침이 병합 적용됩니다.

---

## 3. 대화 및 인터랙션 (Chat UX)

### 3.1 스트리밍 및 방향 전환 (Steering)
- 에이전트가 답변이나 도구를 연속적으로 실행하는 도중에도 입력창에 추가 지시를 타이핑하고 `Enter`를 누르면, 현재 작업이 끝난 직후 해당 지시가 즉시 주입(Steering)되어 방향을 조정합니다.
- 오른쪽 하단의 빨간색 **중지(Square)** 버튼을 누르면 언제든지 생성을 즉시 중단할 수 있습니다.

### 3.2 인라인 시각화 렌더링
- 에이전트 답변에 다이어그램이나 차트가 포함되면 별도 도구 없이 인라인으로 즉시 렌더링됩니다:
  - **Mermaid 다이어그램**: 플로우차트, 시퀀스, 클래스 다이어그램, 아키텍처 등을 SVG로 렌더링.
  - **Recharts 데이터 차트**: 수치 통계나 추이를 막대(Bar), 꺾은선(Line), 영역(Area), 원형(Pie) 차트로 렌더링.
  - 문법 오류가 발생할 경우 앱이 크래시되지 않고 원본 코드가 안전하게 폴백 표시됩니다.

## 4. 보안 및 사람의 승인 (HITL Approval)

Fortress는 2단계 보안 경계를 통해 안전한 작업을 보장합니다:
1. **파일시스템 스코프**: 모든 파일 도구(`read`, `write`, `edit`, `ls`, `grep`, `find`)는 열려 있는 워크스페이스 폴더 내부만 접근 가능하며, 외부 경로는 Rust 커맨드 레벨에서 차단됩니다.
2. **도구 승인 정책 (HITL)**:
   - **위험 도구만 승인 요청 (기본값)**: 파일 쓰기/수정(`write`, `edit`) 및 셸 명령 실행(`shell`) 시 승인 대화상자가 팝업됩니다.
   - **모든 도구 승인 요청**: 읽기 전용 작업을 포함한 모든 도구 호출에 승인을 요구합니다.
   - **자동 승인 (위험)**: 파일 쓰기/수정을 즉시 실행합니다.
   - ⚠️ **셸(`shell`) 도구는 어떠한 승인 모드에서도 항상 실행 전 명령 전문과 함께 승인을 요구합니다.**

## 5. 에이전트 페르소나 관리

- 좌측 액티비티 바에서 **에이전트(Bot)** 아이콘을 클릭하여 에이전트 관리 패널을 엽니다.
- **새 에이전트 생성**: 이름, 전용 시스템 프롬프트, 모델, 온도, 컨텍스트 크기, 사용할 도구 및 스킬 구성을 자유롭게 커스터마이징할 수 있습니다.
- **채팅에서 선택**: 새 채팅 탭을 열 때 입력창 상단의 드롭다운에서 원하는 에이전트 페르소나를 선택하여 대화를 시작할 수 있습니다.
- **사용 통계**: 에이전트 편집 화면의 "사용 통계" 탭에서 해당 페르소나로 진행된 대화 세션 수 및 메시지 추이를 확인할 수 있습니다.

---

## 6. 에이전트 스킬 (Agent Skills)

- [Agent Skills 오픈 표준](https://agentskills.io)을 준수합니다.
- 워크스페이스의 `.agents/skills/<스킬명>/SKILL.md` 또는 전역 스킬 폴더에 마크다운 문서를 추가하면 에이전트가 이를 스캔합니다.
- **프로그레시브 디스클로저**: 평소에는 스킬의 이름과 한 줄 설명만 컨텍스트에 포함되며, 모델이 관련 작업이라고 판단할 때 본문을 동적으로 로드합니다.
- **수동 스킬 호출**: 채팅창에 `/skill:<이름> [추가 내용]`을 입력하면 즉시 해당 스킬 본문을 대화에 주입할 수 있습니다.

## 7. 단축키 안내

| 단축키 | 기능 |
| :--- | :--- |
| **Ctrl + N** / **Cmd + N** | 새 채팅 탭 열기 |
| **Ctrl + W** / **Cmd + W** | 현재 활성 탭 닫기 |
| **Ctrl + ,** / **Cmd + ,** | 설정(Settings) 페이지 열기 |
| **Escape** | 승인 대화상자 취소 및 팝업 닫기 |
| **Shift + Enter** | 메시지 줄바꿈 |
| **/compact** | 현재 대화 기록 수동 요약 및 컨텍스트 압축 |

## 8. 자동 평가 (Evaluation) — 구현 진행 중

평가셋(팩)을 이용해 여러 후보(모델×설정)를 같은 조건으로 자동 실행하고,
품질·에이전트·성능·자원·신뢰성을 0~100 공통 척도로 비교해 최적 후보를 추천받는 기능입니다.
현재 기획(P10-00) 완료, 실행·UI(P10-01~26) 구현 전이며, 자세한 사용 흐름은
**[EvaluationGuide.md](./EvaluationGuide.md)**에 설계 기준으로 정리되어 있습니다.

- **[새 평가]** → 마법사 4단계(프로파일 → 평가셋 → 후보·Judge → 확인) → [지금 시작]/[나중에 시작]
- 평가 중에는 모든 채팅 입력·전송이 차단되고, 완료되면 같은 탭이 리포트로 전환됩니다.
- 내장 팩 20종(FAB 11종 + 공개셋 9종), 개인 평가셋, Arena 블라인드 투표,
  EEE JSON·CSV 내보내기를 제공합니다.
